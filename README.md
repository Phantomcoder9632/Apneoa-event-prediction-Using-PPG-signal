##Sleep Apnea Event Prediction using PPG Signals

A 1D Convolutional Neural Network (CNN) built in PyTorch to predict upcoming sleep apnea events. The model analyzes 30-second windows of a patient's Photoplethysmography (PPG) signal to forecast an apnea event 5 seconds in the future.

This repository contains the complete pipeline for data preprocessing (filtering, resampling, and windowing), model training, 5-fold cross-validation, and performance visualization.


🔬 How It Works: Methodology

The model's task is to predict an upcoming apnea event. It works by analyzing a 30-second window of "normal" PPG data (green section) and predicting if an apnea event (red section) will begin after a 5-second lead time (orange section).

🚀 How to Run

1. Setup

Clone the repository and install the required dependencies.

git clone [https://github.com/Phantomcoder9632/Apneoa-event-prediction-Using-PPG-signal.git](https://github.com/Phantomcoder9632/Apneoa-event-prediction-Using-PPG-signal.git)
cd Apneoa-event-prediction-Using-PPG-signal

# Create and activate virtual environment (Optional but recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install requirements
pip install -r requirements.txt
# Or manually: pip install numpy pandas matplotlib seaborn scikit-learn torch scipy tqdm


2. Execution Pipelines

This project is divided into two main pipelines. Please follow the order below.

Part 1: Apnea Detection Pipeline

Process raw data and detect apnea events.

Data Loading

python dataset.py


Preprocessing
Open the notebook and run all cells to clean, normalize, and window the signal data.

jupyter notebook preprocess_dataset.ipynb


Model Training
Train the detection model. Run all cells.

jupyter notebook train.ipynb


Run Detection
Classify apnea events using the trained model.

python detection.py


Part 2: Apnea Prediction Pipeline

Train and test the forecasting model.

Visualization & Verification
Visualize the dataset to verify integrity.

python see_dataest.py


Training & Validation
Train the prediction model and run validation.

python train_val.py


Testing & Demo
Evaluate performance and view prediction demonstrations.

python testing_demo.py
